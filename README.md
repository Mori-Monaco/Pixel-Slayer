# Pixel Slayer

Курсовой проект Тращенко Артём ИСиП-23 2026 год.

## О проекте

2D игра в жанре Top-Down Action, разработанная на движке Unity.  
Проект создан в учебных целях для демонстрации навыков разработки игр.

## Особенности

- Динамичный геймплей
- Пиксельная графика

## Технологии

- Движок: Unity 2022.3.10f1
- Язык программирования: C#
- Графика: Pixel Art
- Система контроля версий: GitHub

## Управление

| Действие        | Клавиша |
|-----------------|---------|
| Движение влево  | A или ⭠ |
| Движение вправо | D или ⭢ |
| Вверх           | W или ⭡ |
| Вниз            | S или ⭣ |
| Атака           | ЛКМ |
| Рывок           | Пробел |
