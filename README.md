# Pixel Slayer

Курсовой проект Тращенко Артём ИСиП-23 2026 год.

## О проекте

2D игра в жанре Top-Down Action, разработанная на движке Unity.  
Проект создан в учебных целях для демонстрации навыков разработки игр.

## Особенности

- Динамичный геймплей
- Пиксельная графика
- Несколько типов врагов

## Технологии

- Движок: Unity 2022.3.10f1
- Язык программирования: C#
- Графика: Pixel Art
- Система контроля версий: Git + GitHub

## Управление

| Действие        | Клавиша |
|-----------------|---------|
| Движение влево  | A |
| Движение вправо | D |
| Вверх           | W |
| Вниз            | S |
| Атака           | ЛКМ |
| Пауза           | ESC |
